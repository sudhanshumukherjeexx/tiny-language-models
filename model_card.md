# TinyLM-27M (TinyStories)

A 26.7M-parameter Llama-style decoder **pretrained from random initialization** on
[TinyStories](https://huggingface.co/datasets/roneneldan/TinyStories). The tokenizer and all
weights were trained from scratch. The architecture is Hugging Face `LlamaForCausalLM`.
Training code, data pipeline and evaluation: https://github.com/sudhanshumukherjeexx/tiny-language-models

## Model description

| | |
|---|---|
| Parameters | 26,747,392 (tied input/output embeddings) |
| Layers / hidden / FFN | 8 / 512 / 1,408 (SwiGLU) |
| Attention | 8 query heads, 2 key/value heads (grouped-query), RoPE θ = 10,000 |
| Normalization | RMSNorm (pre-norm), no biases |
| Context | 512 tokens |
| Tokenizer | byte-level BPE, 8,192 tokens, `<|endoftext|>` = BOS = EOS (id 0), `<|pad|>` (id 1) |

## Training data

TinyStories (Eldan & Li, 2023): synthetic short stories written with a vocabulary that young
children would understand. Text was NFKC-normalized and typographic punctuation was mapped to
ASCII; stories under 100 characters were dropped. The official `validation` split was held out as
the test set, after removing the 29.9 % of its stories that have an exact copy in the official
train split. 0.5 % of the official `train` split (selected by content hash) served as validation
for checkpoint selection.

Dataset revision: `f54c09fd23315a6f9c86f9dc80f725de7d8f9c64`. The dataset is distributed by its authors
under its own license, and this model card claims no ownership of it.

## Training procedure

| | |
|---|---|
| Objective | next-token cross-entropy on packed 512-token sequences |
| Optimizer | AdamW, β = (0.9, 0.95), weight decay 0.1 (matrices only), grad clip 1.0 |
| Learning rate | 6e-4 peak, 200 warmup steps, cosine decay to 0 |
| Batch | 72 sequences × 512 tokens = 36,864 tokens per step |
| Steps / tokens | 12,000 / 442,368,000 (0.95 epochs; 16.5 tokens per parameter) |
| Precision | bf16 autocast (fp32 master weights) |
| Hardware / wall clock | 1 × NVIDIA GeForce RTX 3050 Ti Laptop GPU (4 GB) / 6.26 h (5.81 h in optimizer steps; 21,142 tokens/s; 1,773 MB peak allocated; micro-batch 8 × 9 accumulation) |
| Seed | 1337 (single run) |

## Evaluation

| Metric | Split | Value |
|---|---|---|
| Cross-entropy (nats/token) | validation (model selection) | 1.3895 |
| Cross-entropy (nats/token) | **test** (official TinyStories validation minus exact copies of train; evaluated once) | **1.3842** |
| Perplexity | test | 3.99 |
| Evaluated tokens | test | 3,133,963 predicted tokens (15,388 stories) |

Perplexity depends on the tokenizer, so it is only comparable to models that use this tokenizer.
Generation quality, lexical diversity, memorization analysis and documented failure cases are in
the repository (`results/`).

## Intended uses

* Studying small-language-model pretraining, evaluation and failure modes.
* Teaching and demos of story continuation in simple English.

## Out-of-scope uses

* Any factual, advisory or decision-making use. The model has no world knowledge beyond
  children's stories and was not instruction-tuned or aligned.
* Use as a chat assistant or question-answering system.
* Generating content for children without human review.

## Limitations

* Narrow domain: simple, synthetic, English-only stories. Out-of-domain prompts produce
  story-like text or nonsense.
* Frequent coherence failures: characters change roles, statements contradict each other, causal
  connectives are misused, and morals can contradict the story. See `results/failure_analysis.md`.
* Short 512-token context.
* Memorization: on the evaluation suite, generations were no closer to training stories than
  held-out human-written stories (median nearest-neighbour TF-IDF similarity 0.255 vs. 0.250;
  longest shared span 17 words). They reuse more short stock phrases. Extraction with real
  training prefixes was not tested.
* Long prompts (~200 tokens) make it end the story prematurely and confuse characters.
* Results come from a single training seed unless stated otherwise.

## Bias, risks and safety

TinyStories was generated by GPT-3.5/GPT-4. Its stereotypes (for example in gender roles or
family structures) may be reproduced. The model has no safety tuning, and its outputs should be
reviewed before being shown to anyone, especially children.

## Environmental and compute considerations

Training compute ≈ 6 × parameters × tokens = 6 × 26,747,392 × 442,368,000 ≈ 7.1 × 10¹⁶ FLOPs
(standard dense-transformer estimate, excluding attention). It ran for 6.26 h on one laptop GPU.
Energy use was not measured.

## Reproducibility

```bash
git clone https://github.com/sudhanshumukherjeexx/tiny-language-models && cd tiny-language-models
uv sync --extra cu130          # or --extra cu126 / --extra cpu
uv run python scripts/train_tokenizer.py --config configs/tiny-27m.yaml
uv run python scripts/prepare_data.py   --config configs/tiny-27m.yaml
uv run python scripts/train.py          --config configs/tiny-27m.yaml
uv run python scripts/evaluate.py       --config configs/tiny-27m.yaml
```

Exact library versions are in `uv.lock` and in the run's `environment.json`. Training and test
data are fully determined by the config and the recorded dataset revision.

## How to use

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

tok = AutoTokenizer.from_pretrained("<hf-user>/tinylm-27m", clean_up_tokenization_spaces=False)
model = AutoModelForCausalLM.from_pretrained("<hf-user>/tinylm-27m")
ids = tok("<|endoftext|>Once upon a time", return_tensors="pt", add_special_tokens=False)
out = model.generate(**ids, max_new_tokens=150, do_sample=True, temperature=0.8, top_p=0.9, top_k=0)
print(tok.decode(out[0], skip_special_tokens=True))
```

Or `from tinylm import TinyLM; TinyLM.from_pretrained("<hf-user>/tinylm-27m").generate("Once upon a time")`.
